Windows desktop video workflow

Your highlights.
Ready to share.

ShortsTools helps creators turn gaming moments into vertical videos using a local Windows workflow. Capture a highlight, let FFmpeg prepare the clip, and review it before sharing.

Independent desktop project · In development

Built for a faster creator workflow

01 / CAPTURE

Save highlights

Connect a Stream Deck button to OBS Replay Buffer to save recent gameplay without stopping a stream.

02 / PROCESS

Automatic vertical edits

Process local video files with FFmpeg and an adjustable vertical layout, including gameplay and facecam.

03 / MANAGE

Monitor and share

A Windows tray interface shows processing progress and provides access to finished videos. YouTube uploads are supported in the local beta; TikTok integration is under development and subject to platform approval.

How it works

From key moment to finished short

OBS Replay Buffer → local clip queue → FFmpeg processing → ready-to-review MP4 → optional platform upload. Uploaded content remains subject to each platform's permissions, review, and publishing rules.
