Privacy Policy

This policy describes the current local beta and planned platform integration. Features still under development are identified as such. Review and update this policy if the application changes.

1. About ShortsTools

ShortsTools is an independent Windows desktop workflow for capturing gaming highlights, processing vertical video files, and initiating optional uploads to supported platforms. The public website is informational.

2. Information processed

The desktop application processes the local video files you select or save through your configured workflow, associated filenames, upload metadata (such as titles and descriptions), application settings, and operation logs. When you authorize a connected service, the application can process authorization credentials needed to make API requests on your behalf.

3. Local storage

In the current desktop beta, YouTube OAuth tokens are saved in a local application data directory on your Windows device. Video files, workflow status, and upload history also remain on your device unless you choose to upload a video to an external service. Keep your device and local application data secure; do not share OAuth tokens or client secrets.

4. External platforms

When you authorize an upload, ShortsTools sends the selected video and relevant metadata to the platform you choose. Google/YouTube handles uploaded videos and associated account data under its own policies. TikTok posting integration is in development and requires applicable permissions and platform approval. We do not claim that a public TikTok posting integration is active.

5. Website data

This static site is hosted with GitHub Pages. The site itself does not include its own analytics scripts, sign-in forms, or advertising trackers. GitHub may process technical request information as part of providing site hosting; consult GitHub's privacy statement.

6. Retention and control

You can manage or delete local generated clips, logs, settings, and authorization data on the device where ShortsTools runs. Removing local credentials stops the app from using them, but does not necessarily revoke existing authorization at the platform; revoke access separately in the platform's account security settings. Uploaded content is managed through the destination platform.

7. Security

ShortsTools should only be installed from a trusted source. No application can guarantee absolute security. Never publish access tokens, OAuth secrets, or other private credentials to a public GitHub repository.

8. Updates and contact

We may revise this policy when app features or data handling change. Questions about the project can be directed through the developer's GitHub profile. Do not share sensitive credentials in public messages.
